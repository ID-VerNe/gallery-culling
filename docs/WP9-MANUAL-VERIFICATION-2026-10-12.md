### ⚠️ A-1【最高危】导出目标 == 源目录必须被拒 —— **修复前会真的清空原图**

> **修复前必须先备份：把导出目标设成源目录 → 期望（修复后）立即被拒；期望（修复前应失败）出现原图被清空或导出静默失败。**
> 该用例在**修复前**会真的把原图截断为 0 字节，属**不可逆数据丢失**。**执行前务必：**
> 1. 复制一份**真实照片副本**（不要用原件）到隔离目录，例如 `D:\wp9-sandbox\src`。
> 2. 确认该副本可丢（例如从原始素材重新拷一份即可恢复）。
> 3. 绝不在真实照片库上直接执行"目标=源"这一步。

## 6. 一万张压测构造脚本（摘自 `ux_fix_04_long_task_scale.md` 末节）

```bash
# Windows Git Bash 下执行；每张 ~20–40KB（够触发 EXIF/XMP/缩略图路径，不占满盘）
mkdir -p /tmp/stress/jpg /tmp/stress/raw
python - <<'PY'
import os
from pathlib import Path
MIN_JPEG = bytes.fromhex('ffd8ffe000104a46494600010100000100010000ffdb004300ffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffffc0000b080001000101011100ffc4001f0000010501010101010100000000000000000102030405060708090a0bffda0008010100003f00d2cf20ffd9')
for i in range(10000):
    stem = f"IMG_{i:05d}"
    (Path('/tmp/stress/jpg')/f'{stem}.jpg').write_bytes(MIN_JPEG * 8)
    (Path('/tmp/stress/raw')/f'{stem}.cr3').write_bytes(b'\x00'*32768)
    if i % 3 == 0:
        (Path('/tmp/stress/raw')/f'{stem}.xmp').write_text('<x:xmpmeta xmlns:x="adobe:ns:meta/"><rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"><rdf:Description xmp:Rating="3"/></rdf:RDF></x:xmpmeta>')
print('done')
PY
```

**已知局限（务必随结论一起披露）：**

1. 合成 JPEG 的 EXIF 为空 → 缩略图走"全图 decode"路径，**与真实库（有内嵌缩略图）不同**。要更真实需用 exiftool 批量注入真实 APP1 缩略图。
2. 伪 RAW **不是合法 RAW** → **LUMEN 引擎路径无法真实渲染**。测 LUMEN 冷缓存串行**必须用真实 RAW**（200 张真实 RAW 即可量化单张耗时并外推到 1 万）。
3. 导出压测要用**大文件**（10–80MB）才能体现耗时与取消体验：可把少数文件放大，或专门造"200 × 20MB"的小集合。

**测量点：** ①扫描分段耗时 ②冷启动滚动 30s 内 IPC 次数与掉帧 ③LUMEN 冷缓存首刷 200 张真实 RAW ④导出 200×20MB 耗时 + 取消响应 + 目标目录残留。
