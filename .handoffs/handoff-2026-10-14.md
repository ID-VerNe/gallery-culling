## 4. 项目约定参考

### 4.1 规则来源

**仓库内没有 CLAUDE.md。** 规则在全局 `~/.claude/CLAUDE.md`，相关 7 条：
不保留向后兼容 / 最简实现（不投机抽象）/ 分层增长 / 模块化 + 职责分离 /
优先成熟库 / 长期架构决策 / 禁止 emoji。

### 4.2 本次确立的技术约定

**Rust `#[tauri::command]` 跨模块规则**（FE-07 踩出来的，后续必踩）：

属性宏在**定义它的模块**内生成 `macro_rules!`（`__cmd__xxx` 与
`__tauri_command_name_xxx`），带 `#[macro_export]`。glob 导入（`pub use mod::*`）
**带不出** `macro_rules!`。因此：
- `lib.rs` 的 `generate_handler!` 里必须写**路径限定**：`commands::xxx_cmd`
- 每个命令子模块的宏要在 `mod.rs` 逐个显式转发

**子模块命名避让**：`xmprw`（不叫 `xmp`）、`lumencmds`（不叫 `lumen`）—— 否则与
顶层的 `use crate::xmp` / `use crate::lumen` 同名冲突。

**命名空间 URI 单一真值**：`xmp.rs` 的 `OURS_NAMESPACES` 是 `(prefix, uri)` 成对表，
`build_our_description`（生成 xmlns 声明）与 `splice_our_block`（认本方块）都从它取。
改 URI 只改一处。写出的字节必须与既有侧边栏逐字节一致，否则 Lightroom 会当成模板更换。

### 4.3 测试约定

- 前端测试断言 `invoke` 收到的命令名与参数，不测组件内部实现（`src/test/setup.ts:4-13` 的设计原则）
- 未注册的 Tauri 命令会让测试炸出 `UnmockedCommandError`，用 `mockInvokeCommand` / `mockInvokeError` 声明
- `isTaskCancelled` 按哨兵字符串精确比对，所以 mock 取消要丢**裸字符串**（`throw TASK_CANCELLED_SENTINEL`），
  包成 `Error` 会变成 `"Error: 任务已取消"` 而绕过判定 —— 这是真实链路行为，不是测试取巧
- Rust 侧 `cargo test --lib` 有 1 条既有 flaky：`lumen::tests::drop_closes_stdin_so_child_exits`
