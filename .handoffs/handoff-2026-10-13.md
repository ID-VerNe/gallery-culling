## 4. 项目约定参考

### 4.1 硬性规则（用户明确要求，必须遵守）

- 用**中文**回复、写注释、写 README。
- 每次运行 Python 命令都要先从 `.venv` 激活虚拟环境，在虚拟环境里运行。
- 环境是 **Windows**，**用 PowerShell**，禁止 Linux / cmd 命令。
- Node 包管理用 **pnpm**。
- **本项目禁止 Tailwind CSS v4**，必须始终使用 v3.x 及其配套 PostCSS 配置（当前 `tailwindcss: ^3.4.17`）。
- 个人敏感信息（如私有域名）不得出现在 commit 中。

### 4.2 设计令牌约定

`src/styles/design-tokens.css` 定义在 `@layer base :root`：

| 令牌 | 值 |
|---|---|
| `--color-bg-base` | `#0A0A0A` |
| `--color-bg-surface` / `-hover` / `-header` / `-panel` / `-input` | `white / 2%` / `5%` / `3%` / `6%` / `8%` |
| `--color-border-subtle` / `-default` / `-strong` | `white / 6%` / `20%` / `35%` |
| `--color-bg-button` / `-hover` | `white / 9%` / `14%` |
| `--color-scrollbar-thumb` / `-hover` | `white / 15%` / `25%` |

Tailwind 主题类名映射为 `bg-background-base`、`border-border-default` 等。

### 4.3 组件约定

- 弹窗统一走 `src/components/Modal.tsx`（焦点陷阱、Esc、焦点归还、弹窗栈、`max-h`），确认类弹窗走 `ConfirmDialog.tsx`。
- 焦点可见态统一用 `.focus-ring`（配合 `:focus-visible`）；滑杆统一用 `.tone-slider`。
- 长任务统一用 `useTaskProgress` + `TaskProgressBar`（进度 + 取消 + 看门狗）。
- 通知统一用 `useToast()`（`toast.info / success / error`）。

### 4.4 数据流约定

- `App.tsx` 是单一状态宿主；`selectedIndex` 是相对 `filteredGroups` 的索引，`currentGroup = filteredGroups[selectedIndex]`。
- 调色的**磁盘基线**保存在 `groups[].tone`，编辑中的值保存在 `toneMap[id]`；保存时以滑杆为准同时覆盖 XMP 与 LUMEN RAW 工程。
- 写盘失败用 `unsyncedIds` 做持久标记，不依赖会消失的 toast。

### 5.5 注意事项

- 测试里若按 `getByRole('button', { name: '调色面板' })` 查询会命中**两个**按钮（TopBar 与视口各一个，同名是 A9 修复的结果）；需用 `getAllByRole(...)[0]` 或更精确的查询。
- 宫格搜索框的 `aria-label` 是 `在宫格中按文件名搜索照片`（A3 统一后），不是旧的 `按文件名搜索照片`。
- 不要引入 Tailwind v4 或其新 PostCSS 插件（`@tailwindcss/postcss`），会与现有 v3.4 配置冲突。
- 提交时建议按域拆分，例如：`fix: UX 审计 58 条闭环（域 A/B 外壳与选片）` + `fix: UX 审计 58 条闭环（域 C/D/E 视口、弹窗、反馈）`。
